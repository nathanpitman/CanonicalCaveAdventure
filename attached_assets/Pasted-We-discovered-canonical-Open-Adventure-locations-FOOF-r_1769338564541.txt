PROBLEMS TO FIX:
A) Default travel rules:
- YAML travel entries like {verbs: [], action: [goto, LOC_DEBRIS]} mean “if no travel verb matches, go there”.
- Current importer drops these, creating rooms (foof1/foof3) with only LOOK and no way out.
B) Verb-based travel beyond compass directions:
- YAML uses stems like ENTER, INWAR, DOWN, XYZZY, PLUGH, DEPRE, etc. We must be able to type these words and have them work.
C) Conditional travel (GRATE_CLOSED):
- Example: LOC_GRATE has ENTER/DOWN that only works if grate is open; otherwise it does a speak action GRATE_NOWAY.
- LOC_DEBRIS has DEPRE that works only if grate is NOT closed.
We need a minimal mechanism to enforce this so puzzles don’t become bypassable.
